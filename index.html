기록 모으기 (Google Apps Script)

과목을 하나 끝낼 때마다 구글 스프레드시트에 한 줄씩 쌓입니다. 무료이고 횟수 제한이 없습니다. 여러 학생 기록을 한곳에 모을 수 있습니다.

☁️ Apps Script 설정 방법 (처음 한 번, 약 10분)
  1. 구글 드라이브에서 스프레드시트를 새로 만듭니다.
  2. 메뉴 확장 프로그램 → Apps Script 를 엽니다.
  3. 저장소의 engine/gas/Code.gs 내용을 전부 복사해 붙여 넣습니다. (원래 있던 function myFunction 은 지웁니다)
  4. 맨 위 var SECRET = "곰돌이2026"; 의 글자를 원하는 암호로 바꾸고 저장합니다.
  5. 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱 선택
    다음 사용자로 실행: 나
    액세스 권한이 있는 사용자: 모든 사용자
    배포를 누르고 권한을 허용합니다.
  6. 나온 웹 앱 URL(/exec 로 끝남)을 위 칸에 붙여 넣고, 암호도 같게 적은 뒤 저장합니다.
  7. 아래 연결 시험으로 확인합니다. 스프레드시트에 '기록' 시트가 생기면 성공입니다.

코드를 고친 뒤에는 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포를 해야 반영됩니다.

메일 보내기 설정 (EmailJS)

한 번만 넣어 두면 계속 씁니다. 아래 '설정 방법'을 펼쳐 보세요.

📮 EmailJS 설정 방법 (처음 한 번, 약 10분)
  1. emailjs.com 에 들어가 무료로 가입합니다. (월 200통)
  2. 왼쪽 Email Services → Add New Service → Gmail 선택 → 본인 계정 연결 → 만들어진 Service ID 를 위 칸에 붙여 넣습니다.
  3. 왼쪽 Email Templates → Create New Template. 제목과 내용에 아래를 그대로 넣습니다.
    To Email 칸: {{to_email}}
    Subject 칸: {{subject}}
    Content 칸(Code 편집으로 바꾼 뒤): {{{body_html}}} — 중괄호 세 개입니다. 두 개면 표가 글자로 보입니다.
    저장하면 나오는 Template ID 를 위 칸에 붙여 넣습니다.
  4. 펜 풀이 그림을 함께 받으려면 템플릿 아래 Attachments → Add Attachment → Variable Attachment 를 고르고 Parameter Name 에 solution_image, File Name 에 풀이.png 를 적습니다.
  5. 오른쪽 위 계정 메뉴 → Account → Public Key 를 복사해 위 칸에 붙여 넣습니다.
  6. 저장을 누르고 아래 시험 발송으로 확인합니다.

그림 첨부는 용량 제한이 있어 자동으로 줄여서 보냅니다. 너무 크면 그림 없이 글만 보내고 알려 줍니다.

가장 많이 틀리는 곳 — Content 는 오른쪽 위 </> 를 눌러 코드 편집 모드로 바꾼 뒤 {{{body_html}}} 를 넣어야 합니다. 중괄호가 두 개면 표가 글자 그대로 보입니다.

더 자세한 설명은 저장소의 docs/EmailJS_설정법.md 에 그림 설명 없이 단계별로 적어 두었습니다.
